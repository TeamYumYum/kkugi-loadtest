운영 중인 발생기에서 페르소나의 행동이 바뀐 때를 모은다. DB나 지표에서 어느 날부터 데이터 모양이 달라졌는지 찾을 때 본다.

- 한 번 배포한 변경이 파일 하나다. 이름은 `{적용 날짜}-{주제}.md`다.
- 무엇이 언제부터 어떻게 바뀌었는지와 데이터에서 보이는 차이만 적는다. 이유와 계산은 결정 기록(`notes/decisions/`)에 있고,
  여기서는 링크만 건다. 지금의 규칙은 [페르소나 문서](../personas/)가 기준이다.
- 적용 시각은 관측 서버에 배포한 시각(한국 시간)이다. 그 전에 계획된 일정의 세션도 새 규칙으로 실행된다.
